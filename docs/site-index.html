Give your Rust program control of the desktop.

Move the mouse, type, take screenshots, and find images on screen. Rusty Robot is a Rust reimplementation of RobotJS for apps, tests, and agents.

The implementation is Rust. It calls native operating-system APIs and does not use RobotJS’s C/C++ addon.

cargo add rusty-robot-desktop

macOS 14+, Windows, and Linux/X11. Version 0.1 is an early release; native Wayland is not supported.
