Desktop automation, with the evidence.

Mouse and keyboard input, screen capture, and image search through one native Rust API. An independent implementation of RobotJS’s recorded test contract.

cargo add rusty-robot-desktop

macOS 14+, Windows, and Linux/X11. Version 0.1 is an early release; native Wayland is not supported.

How we built it

Porting RobotJS’s tests, benchmarking against Node.js, and improving Rust with RobotJS’s own algorithms.

Results against RobotJS’s Node.js API, later capture experiments, raw samples, and the limits of each comparison.
