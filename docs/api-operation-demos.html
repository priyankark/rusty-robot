How these videos were recorded

The processes run concurrently on the same Apple M6 Mac. Each performs five warmups, waits for a shared start signal, and checks the answer on every operation. The clocks include assertions and progress reporting; setup is excluded. Both use the same saved input fixtures. Node uses RobotJS’s real native addon; Rust uses the 0.1.3 library source.

The recorder captures only this owned demo window at its original wall-clock pace. It does not replay the archived benchmark numbers or simulate the work. The input image stays visible while the actual API runs report progress. The videos have no audio; all results are also written above.

These are single-run demonstrations with recording and two processes sharing a machine. Use the sequential, repeated benchmark experiment for the reported performance comparison. This does not measure mouse clicks, typing, or screenshot latency.
